# Chikmagalur road trip page

This imported project is a single static `index.html` with inline CSS and JavaScript. It has no package dependencies or build step.

Run the **Start application** workflow to preview it on Replit. The workflow serves the project root with `python3 -m http.server 5000 --bind 0.0.0.0`; opening `/` loads `index.html`.

The page links to externally hosted logo images, Google Maps embeds, and other external sites. Those resources require an internet connection and may be subject to the providers' availability.
